# Development status — November 14, 2026

Working repository: zwbeam/strength-lab-preview, preview branch. Production is
unchanged. README data and promotion boundaries remain authoritative.

Completed batches are recorded in research/development-batches.md. The latest
source inventory and equipment matrix are reproducible with
`node scripts/audit-curriculum.cjs`; instruction-only references are never
scheduled or credited. Source #441 is unusable. External review completion is
retained as accounting evidence, not silently converted into instruction claims.

Current coverage: 54 programmable movements with dedicated lessons and no remaining
instruction-only entries in the current catalog. Uncatalogued source systems
remain incomplete. Thirty-eight outlines are
reviewed; sixteen programmable lessons retain source/visual-verification gaps.
See MOVEMENT-INTEGRATION-COVERAGE.md for every movement's complete-system route,
prerequisites, equipment, profile and remaining boundaries. Eight Book outlines
remain separate and provisional.

New double-club system: explicit owned matched pairs in lb per club, opt-in
preference, swing clean → pullover → four-count technical swipe, recent foundation
practice and explicit skill/overhead gates. Independent app-defined cycles and
load review; one paired-club pattern per session. Performance swipes are excluded.

New bodyweight integration: bear/cat 30/30 timed practice with explicit clear-space
and technique checks; lower-body/ground block plus eligible bodyweight support in
ABC. Actual seconds and bilateral results determine completion. The optional
“Use prescribed intervals” button loads simple side-one timed work into the
existing interval timer without logging work. Missing or reduced work never
qualifies as progression.

Single/paired kettlebell links now use recent single clean before double clean,
single press + double clean before double clean/press, and distinct rack squat +
double clean before double squat. App gates are not universal source prescriptions.
Complexes snapshot one-sequence explanations and keep independent credit. Their
time estimates include component work with conservative app floors.

Clean light work preserves prior prerequisite evidence without adding credit.
Pain, technique issues, incomplete and recovery/re-entry work remain nonqualifying.
All doses/gates for these new systems are explicitly app adaptations; source
facts, numerical examples and unresolved qualifications are stored separately.

Tests include four three-year actual-generator histories with equipment removal,
explicit replacement, missed days, pause, low readiness, poor technique, pain,
partial sessions and repeated backup/replay. Mobile acceptance covers each of
the three paired-club movements plus crawl timing/logging. Run ALL Node/CJS and
browser suites; require BOTH current-commit audit and browser jobs before QA.
These are synthetic histories and touch browser emulation, not clinical outcomes
or physical Android/technique validation.

Remaining: performance-swipe and broader numerical double-club systems, bodyweight/paired
kettlebell pathways and complexes, visual technique validation and missing source
mappings. Mixed schedules with too many independently rotated movements can
require frequent re-entry. Movement-level cadence feedback and bounded follow-up priority now reduce avoidable
re-entry; broad schedules can still exceed a sustainable return cadence. Keep
eligibility gates intact when refining selection.
The master source ledger/anchored external reviews remain unavailable, so source
accounting completion must not be presented as full engine integration.

Continue from NEXT-CONTINUATION.md. Preserve V33 keys, backup compatibility,
active drafts, writer locks, correction replay and archived recovery branches.


Continuity checkpoint: coordinated programs default to protecting eligible
movements near the configured return window, then a bounded follow-up after
clean reduced return practice. At most two extra consecutive sessions when
another block is ready. Advanced Settings can disable this priority. Warnings
name up to three affected movements; only compact feedback is stored in plan
snapshots. Provisional future sessions never assume a follow-up was performed.
All doses, load choices, recovery gates and source profiles remain unchanged.


Alternating double-club checkpoint: inside and outside circles now have a separate
opt-in automatic skill-practice block. Explicit held-club control, recent paired
and single-arm foundations and owned club pairs gate eligibility. Outside uses
recent inside practice; per-side actual counts are required. The foundation
block and ABC pool are unchanged. Numeric practice doses/rest are app adaptations,
not the full #151 strength/bodybuilding progression. Visual technique remains
incomplete. This closes the two instructional-only catalog gaps without claiming
all research movements are implemented.


First-use load setup: Advanced Movement Programming now offers owned-equipment
starting-load selection for unstarted loaded movements, including paired clubs
and kettlebells. It cannot replace an established working load or certify a
skill. Existing unavailable-load replacement controls are reachable there too.
Browser regression starts with the target load unset, selects it through Settings,
reloads and completes the generated workout. Prior seeded-load tests had not
covered this reachability gap.


Sliding-plank foundations: sources #86/#94 support a knee-supported stage and
outbound knee-hover/knee-down return. Both use explicit skills and recent practice
before the harder stage. The opt-in block and eligible basic ABC support use
app rep/set/rest/time estimates; no source numeric dose or mastery is invented.

Secured-bar bent-knee horizontal rows now have an opt-in block and eligible ABC
support. Bar availability, configured height and explicit skill confirmation are
required. Actual geometry changes receive no progression credit; changing the
configured height starts a separate comparison cycle. Source #89 supplies technique
and qualifications, while the conservative dose is an app default. Full source
60/80 programming and straight/elevated-leg variants remain unimplemented.

Unloaded step-up foundations now support alternating-lead and static-foot patterns
from source #97. Stable platform/overhead-clearance confirmation, recorded height
and separate explicit skills are required; both sides must be recorded. Each
pattern has independent volume credit. Height changes start separate comparison
cycles; neither height nor external load increases automatically. The two patterns
are alternatives, not an invented mandatory prerequisite ladder. Dose, rest,
planning pace and comparison gates are Strength Lab choices.

Double-kettlebell deadlift and swing now have a dedicated opt-in hinge block.
Source #142 supports paired deadlift before swing, substantial single-bell
preparation, lighter familiar per-bell loading and controlled parking. Explicit
experience/technique confirmation remains separate from the app recency gate:
recent paired deadlifts and single swings precede double swing. Doses, rest,
planning pace and load caps are app choices. No automatic 60% loading, multi-year
certification or 6-to-20 rep cycle is inferred. Existing paired clean/press/squat
paths and histories are unchanged; broader source ordering remains incomplete.

Program-continuity correction: coordinated plans omit unstarted zero-load
placeholders and report setup needs instead of treating them as unfinished
physical training. Legacy mixed histories can resume their rotation; actual
partial work is still prioritized. Qualified recent descendants can maintain
previously earned prerequisite recency along registry-gated chains. Every
ancestor still needs its own clean evidence, matching policy/load, explicit skills
and no unresolved pain or newer failed work. No parent progression is awarded.
See TRAINING-RULES.md for implementation boundaries.

Hand-to-hand swings now have an opt-in single-bell practice block from #185.
Recent two-hand swing practice and separate hand-change confirmation are required.
Per-driving-hand counts, 2–4 sets of 5 per hand, 90-second rests, planning pace
and load review are app defaults; the source supplies no numerical program.
Alternating work never earns two-hand or paired movement progression. Existing
paired readiness gates remain unchanged. Ordinary repetitions stay untimed, and
timer activity never logs work. Broader one-arm/outside swing systems remain gaps.

Timer Start now begins interval playback immediately after the explicit tap.
Earlier automation masked a paused-start defect by pressing Resume next. New
unit and touch-browser assertions check Start alone and rendered elapsed time;
reload remains deliberately stopped and timer activity never logs physical work.
Physical Android audio/background verification remains a user-review item.


Introductory single-arm swing checkpoint: #67 now has a separate opt-in
singleArmSwingPractice block, explicit thumb-back technique confirmation and
recent two-hand foundation practice. #446 distinguishes soft-style endurance;
that skill is not prescribed here. Bilateral actuals, owned starting load,
independent progression, correction replay and offline drafts use existing
contracts. The 2–4 sets, 3–5 per side, 90-second rest and gates are app choices.
Hand-change and paired histories/admission are preserved. Coverage is now 54
programmable lessons, 38 reviewed outlines and 16 explicit instructional gaps.
