# User review checkpoint — source curriculum batch

Keep the established training notebook, Training Plan, eight Book outlines and
separate Movement Library. No additional major interface redesign is approved.
Build → automated verification → DEV preview → user review → refinement.
Passing tests do not establish user satisfaction or physical Android behavior.

What changed: Learn no longer crashes on missing complex entries; movement
categories include new practical foundation lessons and clearly marked
instruction-only crawl/double-club references. Optional Movement Programming is
reachable in Advanced Settings; default A/B/C is unchanged. History date filters
and pagination preserve the open disclosure and never modify stored records.

Please test on Android: open each Learn category, check readability and video
opening, return to Train, and confirm existing saved history/timer behavior.
If deliberately testing optional blocks, export a backup first; confirm only
techniques you already perform safely. Report confusing wording or controls.
Physical-device/audio/technique validation and full curriculum integration are
not completed by browser emulation. Book chapters remain unpublished outlines.


Follow-up: single-rack front squat has distinct instruction, practice and future
complex eligibility. Goblet history alone does not establish rack competence.
Unrecorded left/right result fields stay blank, matching the existing explicit-
actual save requirement. Check that these fields and the save feedback are clear
on your phone. Double-club swing-clean is educational, not automatically dosed.


Lifelong integration review: Settings now includes explicit matched club pairs
and clear crawl space. Learn distinguishes the three programmable double-club
foundations and programmable crawls from the two remaining instructional-only
alternating patterns. Normal ABC can include eligible bodyweight support and
opt-in paired clubs. Progress separates the technical club combination. Ordinary
repetition work stays untimed. “Use prescribed intervals” copies a simple timed
prescription into the existing timer; it neither starts physical work nor marks
sets performed. Please review wording, interval setup and selection coherence on
Android. Broader mixed programs can still revisit movements too infrequently;
this is an open programming-continuity issue, not evidence of failed training.


Continuity review: Why this workout now explains bounded return follow-ups and
movement retention priority. Rotation notes name actual repeatedly returning
patterns. Advanced Movement Programming has an opt-out; existing block choices
and history are retained. Check that these explanations help you understand the
next workout and that upcoming weeks remain visibly provisional. No new major
interface redesign is introduced.


Alternating-club review: the two remaining double-club references are now
programmable in an opt-in skill block, with explicit familiarity and recent
foundation gates. Ordinary default programs are unchanged. Per-side results are
required in the existing set editor. Please review the dose/eligibility wording;
source bodybuilding examples are not an automatic progression ladder.


First-use setup review: open Advanced Movement Programming, expand an unstarted
loaded movement and choose a familiar owned starting load. Paired selections
use per-implement inventory. Established loads continue through review/progression
controls; unavailable loads use explicit replacement. Please check that this
route and the eligibility explanations are clear on Android.


Sliding-plank review: the basic and hover variants are available in Learn and
Advanced Movement Programming. The harder stage needs recent supported practice
and separate skill confirmation. Inspect the rep/rest prescription and return
sequence; the timer does not invent a work countdown for these ordinary reps.


### Secured-bar row review checkpoint
Equipment setup now asks whether a secured stable row bar is available and records
its height. Generated rows show the written setup; only row editors expose optional
geometry fields. Changed height or straight legs are recorded without earning
credit against the original bent-knee setup. History correction preserves the
original prescription and supports undo. Please review on physical Android before
any further major interface changes; browser touch emulation is not device testing.


### Step-up foundation review checkpoint
Training Setup can record a stable platform and familiar height. Advanced
programming offers an unloaded step-up block with alternating-lead and static-foot
days, independent skill confirmation and no automatic height increase. Prescriptions
show platform height; optional actual-setup controls appear only for these movements.
Please test equipment setup, both-side logging, changed-height records and history
corrections on Android. No major interface redesign is included. The app cannot
certify apparatus stability, technique or overhead clearance.


### Paired-kettlebell hinge review checkpoint
Advanced Movement Programming offers Double-kettlebell hinge foundations, with
separate owned starting loads for paired deadlift and swing. Explicit experience
and technique confirmation is required; paired load is shown in kg per bell.
The source-linked lessons explain lighter paired preparation and controlled
set-down. Please test setup, foundation scheduling and modified set logging on
Android. Existing clean/press/squat admission and all saved data remain intact.
No major interface redesign is included.


### Program continuity and hand-change review checkpoint
Coordinated plans distinguish unconfigured starting loads from physical work,
while keeping genuinely unfinished prescriptions in the queue. Recent qualified
advanced practice can maintain previously earned prerequisite eligibility without
creating foundation credit. The hand-to-hand swing block and Learn lesson show
per-hand counting explicitly; actual left/right work and history correction use
the existing editor. Please test these workflows on Android. No major interface
redesign is included, and automation does not substitute for usability review.

Timer interaction correction: explicit Start now starts the interval countdown
instead of only preparing a paused sequence. Earlier tests immediately pressed
Resume and therefore missed this behavior. Regression now checks Start alone,
the rendered countdown, pause, instruction-dialog continuity and absence of
physical-work credit. Reload still stops playback pending deliberate resume.
Please verify this interaction and audible signals on physical Android.


### Optional row volume-wave review
Advanced Movement Programming keeps fixed-dose rows and offers a separate
60%/80% profile. Confirm the secured bar, height and familiar skill, then review
a clean baseline at that setup. The app does not request a maximum test. Check
lower/higher-rep targets, the whole-set rounding explanation and independent
track counts. Baseline review/restart is explicit, including after changing bar
height, and never deletes saved rows. Please review this wording and the ordinary
untimed logging on physical Android; automated touch tests do not certify technique.
